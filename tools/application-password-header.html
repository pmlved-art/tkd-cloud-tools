Authorization для технічного користувача

Збережіть файл і відкрийте локально (file://), за потреби вимкніть мережу. Використовуйте лише окремий Application Password користувача tkd-cloud. Результат рівнозначний паролю: перенесіть лише в захищене поле секрету TKD_CLOUD_AUTHORIZATION для tkd-ukraine.com.ua, не в чат або Git.

Сторінка не виконує мережевих запитів, не використовує сховищ або clipboard API. Після перенесення очистіть поля, закрийте вкладку й очистіть буфер обміну. Браузер та розширення залишаються під вашим контролем; не зберігайте заповнену сторінку.
